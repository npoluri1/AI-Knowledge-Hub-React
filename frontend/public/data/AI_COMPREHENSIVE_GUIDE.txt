[SECTION 023] PROMPTING TECHNIQUES GUIDE
================================================================================
Technique	Category	Description	Best For
Zero-shot Prompt	Basic	Ask directly with no examples	Simple tasks
Few-shot Prompt	Basic	Provide 2-5 examples before asking	Pattern learning
Chain-of-Thought (CoT)	Reasoning	"Let's think step by step"	Complex reasoning, math
Tree-of-Thought (ToT)	Reasoning	Explore multiple reasoning paths	Creative problem solving
ReAct (Reason + Act)	Agent	Interleaved reasoning and actions	Agent tool use
Self-Consistency	Reasoning	Multiple CoT paths, majority vote	Reliable answers
Reflexion	Agent	Self-critique and refine output	Agent self-improvement
System Persona	Structure	Assign a role/persona to the model	Consistent tone/style
Structured Output	Formatting	Request JSON / XML / Markdown output	Programmatic use
Step-back Prompting	Reasoning	Ask for high-level view first then details	Complex analysis
Generated Knowledge	RAG-like	Ask model to generate knowledge first	Improve factual accuracy
Chain-of-Verification	Factual	Generate then verify claims	Reduce hallucination
EmotionPrompt	Engagement	Add emotional cues ("This is important")	Better quality responses
Persona Pattern	Persona	"Act as an expert X who Y..."	Domain-specific tasks
RAG (Retrieval-Augmented)	Knowledge	Provide retrieved context before answer	Knowledge-grounded Q&A
Constrained Generation	Structure	Regex or schema-guided output	Predictable formats
Tool Use Format	Agent	Define tools in system prompt	Agent tool calling
Meta Prompting	Meta	Prompt about prompting itself	Prompt optimization
Few-shot with Chain-of-Thought	Combined	Examples + reasoning chain	Math word problems
Contrastive Prompting	Reasoning	Show what NOT to do	Avoiding mistakes
Skeleton-of-Thought	Speed	Generate outline first, then expand	Faster long-form generation
Multimodal Prompting	Multimodal	Combine text + image + audio	Vision/language tasks
Prompt Chaining	Pipeline	Chain multiple prompts together	Complex workflows
Decomposition	Structure	Break question into sub-questions	Complex multi-step problems
Chain-of-Density	Summarization	Increasingly dense summaries	Summarization
Summary of Summary	Summarization	Hierarchical summarization	Very long documents

[SECTION 025] GLOSSARY OF KEY TERMS
================================================================================
Term	Definition
LLM	Large Language Model - neural network trained on massive text data
RAG	Retrieval Augmented Generation - add relevant context from external data before generating
Agent	Autonomous LLM that can use tools, make decisions, and take actions
MCP	Model Context Protocol - Anthropic standard for LLM-context/tool integration
LangGraph	Graph-based framework for building stateful, multi-agent LLM applications
LangChain	Framework for building LLM-powered applications (RAG, agents, chains)
Vector Database	Database optimized for similarity search on embedding vectors
Embedding	Numerical representation of text/data for similarity comparison
Fine-tuning	Further training a pre-trained model on specific data
RAG Pipeline	End-to-end flow: query -> retrieve relevant docs -> generate with context
CoT	Chain of Thought - reasoning technique prompting step-by-step thinking
MoE	Mixture of Experts - model architecture using multiple specialized sub-models
Quantization	Reducing model precision (32-bit -> 4/8 bit) for smaller size, faster inference
LoRA	Low-Rank Adaptation - efficient fine-tuning method
QLoRA	Quantized LoRA - LoRA with quantized base model for memory-efficient fine-tuning
Vibe Coding	AI-assisted coding style where developer describes intent in natural language
Hermes (Agent)	AI agent platform mentioned in Reddit SG builder thread
Agent-to-Agent	Protocols/patterns for AI agents communicating with each other
Pydantic AI	Type-safe AI agent framework built on Pydantic
Semantic Kernel	Microsoft AI orchestration SDK for building AI agents
AutoGen	Microsoft multi-agent conversation framework
CrewAI	Multi-agent orchestration with role-based agents
Agentic AI	AI systems that can autonomously pursue goals and use tools
SWE-agent	Agent specialized in software engineering tasks
Attribution	Providing source citations in LLM outputs for transparency
Hallucination	LLM generating false or fabricated information
Grounding	Connecting LLM outputs to verifiable sources or data
