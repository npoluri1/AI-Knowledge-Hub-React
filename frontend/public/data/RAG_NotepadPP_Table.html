Pipeline Step-by-Step

Step Component Description Code Snippet Real App Failure Mode
1 User Query Raw question from user. Vague, incomplete, phrased nothing like your documents. user_input = "tell me about the policy changes last quarter" Customer support chatbot receives "my bill is wrong" Ambiguous intent → wrong retrieval
2 Query Processing Rewriting, decomposition, HyDE. Raw question is almost never the query you actually search with. query = rewrite(user_query)\nsub_queries = decompose(query)\nhyde_docs = hyde_generate(query) "my bill is wrong" → "billing dispute process Q3 2025" Poor rewriting → irrelevant chunks retrieved
3 Embedding Query becomes a vector. Meaning compressed into numbers for similarity search. vector = embed_model.encode(query)\n# text-embedding-3-small | bge-large-en-v1.5 Encode rewritten query to 1536-dim vector for vector DB search Domain shift → embedding doesn't capture intent
4 Hybrid Search Vector + BM25. RRF fusion. Catches meaning AND exact terms (policy codes, product IDs). vec_results = vector_search(query)\nbm25_results = bm25_search(query)\nfused = rrf_fusion(vec_results, bm25_results) Healthcare: search "CPT-99213" + "follow-up visit" Pure vector misses exact codes; pure BM25 misses synonyms
5 Vector Database Top-K returns. K = 20-50, not 5. Recall first, precision later. results = vector_db.query(vector, k=30)\n# recall first, rerank later Pinecone / Weaviate / Qdrant returning 30 candidate chunks K too small → miss relevant context
6 Reranking Cross-encoder scores query+chunk together. 20 mediocre → 5 great. Most skipped step. pairs = [(query, c) for c in candidates]\nscores = cross_encoder(pairs)\ntop_5 = take_top_k(candidates, scores, 5) Banking compliance: exact policy clause must be top-1 No reranker → noise reaches context window
7 Context Assembly Dedupe. Order. Trim to token budget. Attach citations. Built artifact with audit trail. ctx = deduplicate(top_5)\nctx = order_by_relevance(ctx)\nctx = trim_to_budget(ctx, max_tokens=4096)\nctx = attach_citations(ctx) Regulated: each chunk tagged with source doc, page, version No citations → compliance violation
8 Generation Model answers using ONLY assembled context. Instruct-tuned LLM with system prompt guardrails. prompt = f"Context:{ctx}\nAnswer based only on context."\nresponse = llm.generate(prompt) GPT-4 / Claude / Llama generating final answer from curated context Context overflow → model ignores relevant parts
9 Grounding Check Every claim traced to source chunk. No source → no claim. Survives audit. claims = extract_claims(response)\nfor c in claims:\n assert trace_to_source(c, ctx) Healthcare: each medical claim must cite the guideline document No grounding → hallucination with confidence

Where Hallucinations Actually Enter

Entry Point Root Cause Fix / Mitigation
Chunking Splits ideas mid-thought → incomplete context Semantic chunking with sentence boundaries; overlap 10-15%
Stale Indexes Serves last quarter's truth → outdated answers Automated re-indexing pipeline; TTL-based cache invalidation
No Reranker Noise and irrelevant chunks reach context window Cross-encoder reranker (Cohere rerank, BGE-reranker)
No Grounding Model fills gaps with confident fabrication Claim extraction + source verification; reject ungrounded claims

Key Insights & Engineering Principles

Insight Explanation Action
Embedding Model is NOT the bottleneck Teams chase 2% gain swapping models while pipeline bleeds 20% at missing steps Fix pipeline fundamentals before tuning embeddings
Hybrid Search is non-negotiable Enterprise data has codes (CPT, policy numbers) that vector search misses Always implement vector + BM25 + RRF fusion
Reranking is the most skipped step Cross-encoder scores query+chunk together for precision Most "broken RAG" just needs a reranker
Audit trail is mandatory in regulated Context must be a built artifact with citations Track source doc, page, version per chunk
Agentic Retrieval is the future Agent decides when/what to search and if results are good enough Build query planning + result evaluation loops

RRF fusion: reciprocal rank fusion fused = {} for rank, doc in enumerate(vec_scores): fused[doc.id] = fused.get(doc.id, 0) + 1/(60 + rank) for rank, doc in enumerate(bm25_scores): fused[doc.id] = fused.get(doc.id, 0) + 1/(60 + rank) ranked = sorted(fused.items(), key=lambda x: x[1], reverse=True) return [doc_map[doc_id] for doc_id, _ in ranked[:k]] # Step 5: Vector DB Query results = hybrid_search(query, k=30) # Recall first # Step 6: Reranking with Cross-Encoder def rerank(query: str, candidates: List[Dict], top_k: int = 5) -> List[Dict]: pairs = [(query, c.text) for c in candidates] scores = cross_encoder.predict(pairs) scored = list(zip(candidates, scores)) scored.sort(key=lambda x: x[1], reverse=True) return [doc for doc, _ in scored[:top_k]] top_5 = rerank(query, results, top_k=5) # Step 7: Context Assembly def assemble_context(docs: List[Dict], max_tokens: int = 4096) -> Tuple[str, List[str]]: context_parts = [] citations = [] token_count = 0 for doc in docs: text = doc.text tokens = len(text) // 4 # rough estimate if token_count + tokens > max_tokens: break context_parts.append(text) citations.append(doc.source) # audit trail token_count += tokens return "\n\n".join(context_parts), citations context, citations = assemble_context(top_5) # Step 8: Generation system_prompt = "Answer using ONLY the provided context." response = llm.generate(system_prompt + "\nContext:\n" + context) # Step 9: Grounding Check def grounding_check(response: str, context: str) -> bool: claims = extract_claims(response) for claim in claims: if not any(claim.lower() in chunk.lower() for chunk in context.split("\n\n")): return False # Ungrounded claim detected! return True if not grounding_check(response, context): response = "I cannot verify this answer from the available sources."
