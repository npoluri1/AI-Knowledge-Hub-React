01 Python Foundations

Async Programming (asyncio)

Single-threaded concurrency with coroutines (async/await), event loops, tasks. Critical for AI APIs — fetch from multiple LLMs/vector DBs concurrently. Key APIs: asyncio.run(), create_task(), gather(), wait_for(), as_completed().

Code: Async Telemetry Aggregator
import asyncio, random async def fetch_telemetry(domain, delay): await asyncio.sleep(delay) return {"domain": domain, "payload": random.uniform(20,100)} async def aggregate(): tasks = [asyncio.wait_for(fetch_telemetry(d,t), timeout=2.0) for d,t in [("Medical",0.5),("Finance",1.5)]] for done in asyncio.as_completed(tasks): r = await done; print(f"[OK] {r['domain']}: {r['payload']:.2f}") await aggregate()

02 LLM Fundamentals

Transformer Architecture

All modern LLMs use the Transformer (Attention Is All You Need, 2017). Key: self-attention (QKV matrices), multi-head attention, positional encoding, feed-forward networks, layer norm, residual connections. Scaling laws predict performance from model size, data, compute.

Key Parameters

Temperature (0.0=deterministic, 1.0=creative), Top-p (nucleus sampling, cumulative probability), Top-k (top K tokens), Max tokens (output limit), Stop sequences (end generation), Frequency/Presence penalty (reduce repetition).

Code: LLM API Wrapper (OpenAI + Anthropic)
from openai import OpenAI from anthropic import Anthropic class LLMWrapper: def __init__(self, provider="openai"): self.client = OpenAI() if provider=="openai" else Anthropic() self.provider = provider def generate(self, prompt, temp=0.7): if self.provider == "openai": r = self.client.chat.completions.create(model="gpt-4o", messages=[{"role":"user","content":prompt}], temperature=temp) return r.choices[0].message.content else: r = self.client.messages.create(model="claude-sonnet-4", max_tokens=4096, messages=[{"role":"user","content":prompt}]) return r.content[0].text

03 RAG Pipeline

End-to-End RAG Flow

Query → Preprocessing → Embedding → Vector DB Retrieval → Context Augmentation → Prompt Engineering → LLM → Grounding Check → Output. Critical for enterprise knowledge apps. Reduces hallucinations by grounding LLM in retrieved documents.

Code: RAG Pipeline with LangChain + ChromaDB
from langchain_community.document_loaders import TextLoader from langchain.text_splitter import RecursiveCharacterTextSplitter from langchain_community.embeddings import OpenAIEmbeddings from langchain_community.vectorstores import Chroma from langchain.chains import RetrievalQA from langchain_community.chat_models import ChatOpenAI loader = TextLoader("docs.txt") docs = loader.load() splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200) chunks = splitter.split_documents(docs) vectorstore = Chroma.from_documents(chunks, OpenAIEmbeddings()) qa = RetrievalQA.from_chain_type( llm=ChatOpenAI(model="gpt-4o-mini"), retriever=vectorstore.as_retriever(search_kwargs={"k":4})) result = qa.invoke({"query": "What is the refund policy?"}) print(result["result"])

Chunking Strategies

Recursive split (default, balanced), Semantic chunking (topic boundaries), Document-based (markdown headers, HTML sections), Agentic chunking (LLM decides boundaries). Chunk size 500-1500 tokens, overlap 10-20%.

05 Agent Frameworks (LangChain/LangGraph)

LangChain LCEL

Declarative chain composition using | operator. Runnable interface: invoke(), stream(), batch(). Components: prompts, models, retrievers, tools, output parsers — all composable via LCEL.

LangGraph StateGraph

Graph-based agent orchestration with cycles, branching, persistence. Key: nodes (compute), edges (transitions), state (shared context). Supports human-in-loop via interrupt/checkpoint.

Code: LangGraph State Machine (2 nodes)
from typing import TypedDict, Literal from langgraph.graph import StateGraph, END class State(TypedDict): query: str; response: str; needs_review: bool def process(state: State) -> State: state["response"] = f"Answer for: {state['query']}" state["needs_review"] = "urgent" in state["query"] return state def review(state: State) -> State: state["response"] += " [REVIEWED]"; return state def should_review(state: State) -> Literal["review", "end"]: return "review" if state["needs_review"] else "end" graph = StateGraph(State) graph.add_node("process", process); graph.set_entry_point("process") graph.add_node("review", review) graph.add_conditional_edges("process", should_review, {"review": "review", "end": END}) graph.add_edge("review", END) app = graph.compile() result = app.invoke({"query": "urgent refund request", "response": "", "needs_review": False}) print(result["response"])

06 Agent Protocols (MCP / A2A / ACP)

MCP (Model Context Protocol)

Anthropic's open protocol for connecting AI to tools/data. Tools (functions AI can call), Resources (data files/documents), Prompts (templates). Server exposes capabilities; client (AI) discovers and calls them. MCP Python SDK available.

Other Protocols

A2A (Google, agent-to-agent), ACP (IBM, broker-mediated), ANP (decentralized networks), OpenAI Function Calling (native tool use), Toolformer (Meta, self-supervised tool learning).

Code: MCP Tool Server (Python SDK)
from mcp.server.fastmcp import FastMCP mcp = FastMCP("docs-server") @mcp.tool def search_docs(query: str, limit: int = 5) -> list[dict]: """Search documentation for relevant passages.""" return [{"title": "Example", "content": f"Result for: {query}"}] @mcp.resource("docs://recent") def get_recent() -> str: """Recent documentation updates.""" return "# Recent Docs\n- v2.1 API changes" mcp.run() # Runs stdio server

07 Multi-Agent Systems

Architecture Patterns

Supervisor: One agent routes to specialists. Team/Crew: Role-based agents (researcher, writer, critic). Debate: Agents discuss to improve output. Hierarchical: Manager delegates to sub-agents. Swarm: Lightweight routines with handoff. Orchestrator-Worker: Orchestrator delegates sub-tasks.

Code: Supervisor Multi-Agent with LangGraph
from langgraph.graph import StateGraph, END, MessagesState from langgraph.prebuilt import ToolNode def supervisor(state: MessagesState): """Route to specialist or end.""" msg = state["messages"][-1].content.lower() if "research" in msg: return {"next": "researcher"} elif "write" in msg: return {"next": "writer"} else: return {"next": "END"} def researcher(state): return {"messages":[{"role":"assistant","content":"Research results"}]} def writer(state): return {"messages":[{"role":"assistant","content":"Written output"}]} builder = StateGraph(MessagesState) builder.add_node("supervisor", supervisor); builder.set_entry_point("supervisor") builder.add_node("researcher", researcher); builder.add_node("writer", writer) builder.add_conditional_edges("supervisor", lambda s: s["next"]) builder.add_edge("researcher", END); builder.add_edge("writer", END) app = builder.compile()

08 Advanced RAG Techniques

Technique Overview

HyDE: Generate hypothetical answer → embed that → retrieve similar docs. Multi-Query: LLM generates multiple query variations. MMR: Maximum Marginal Relevance — balance relevance + diversity. Reranking: Cross-encoder scores initial results. GraphRAG: Microsoft's knowledge graph-based RAG. CAG: Cache-Augmented Generation. CRAG: Corrective RAG with self-reflection.

09 Fine-Tuning & Local Models

LoRA/QLoRA

LoRA (Low-Rank Adaptation): Train small rank matrices instead of full weights. 10K× fewer params, 2-3% accuracy loss. QLoRA: 4-bit quantized LoRA — fine-tune 65B model on single 48GB GPU. PEFT library from HF handles all methods.

Ollama Modelfile

Customize models locally: change temperature, system prompt, template, add LoRA adapters. ollama create mymodel -f Modelfile. Quantization via GGUF (Q4_K_M, Q5_K_M, Q8_0).

Code: LoRA Fine-Tuning with PEFT
from transformers import AutoModelForCausalLM, AutoTokenizer from peft import LoraConfig, get_peft_model, TaskType from datasets import load_dataset model = AutoModelForCausalLM.from_pretrained("microsoft/Phi-3-mini-4k-instruct") lora_config = LoraConfig( r=16, lora_alpha=32, target_modules=["q_proj","v_proj"], lora_dropout=0.1, bias="none", task_type=TaskType.CAUSAL_LM) model = get_peft_model(model, lora_config) print(f"Trainable: {model.num_parameters(True)/1e6:.1f}M params")

from dataclasses import dataclass @dataclass class ModelTier: name: str; cost_per_1k_input: float; cost_per_1k_output: float; max_complexity: int TIERS = [ ModelTier("gpt-4o-mini", 0.00015, 0.0006, 4), ModelTier("gpt-4o", 0.0025, 0.01, 7), ModelTier("claude-sonnet-4", 0.003, 0.015, 10), ] class CostAwareRouter: def select_model(self, query): return max((t for t in TIERS if t.max_complexity >= self._complexity(query)), key=lambda t: t.max_complexity) def _complexity(self, q): l = len(q.split()); return 2 if l < 10 else 5 if l < 30 else 8
