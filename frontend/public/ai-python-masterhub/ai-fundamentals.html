1What Is Artificial Intelligence?

What & why. AI is the science and engineering of making machines that perceive, reason, learn and act rationally. The modern definition focuses on rational agents: systems that choose actions expected to maximize their performance given what they observe and know.

Internal Behavior — How It Actually Works The agent loop runs in a continuous cycle. At each tick: (1) perceive — sensors or API calls feed raw data into the system (camera frames, user messages, database rows). (2) update state — the internal model merges new percepts with existing memory (a knowledge base, a neural network's hidden state, or a vector store). (3) decide — the policy function evaluates possible actions against the current state and selects the one with highest expected utility. (4) act — effectors execute the chosen action (send an API call, move a robot arm, generate text). The cycle repeats. What makes this "AI" rather than "software" is that the policy is learned or inferred, not hand-coded for every case. A thermostat is a trivial agent (percept: temperature; policy: if below threshold, turn on heater). GPT-4 is a complex agent (percept: token sequence; policy: neural network predicting next token; action: generated text). The abstraction scales from trivial to superhuman. 
# The agent abstraction: every AI system is an agent
# percepts  ->  internal state  ->  actions
#   |            |                    |
# sensors       memory & model        effectors

class Agent:
    def __init__(self, model, policy):
        self.model = model      # world model / knowledge
        self.policy = policy    # chooses actions

    def act(self, percept):
        self.model.update(percept)      # learn / track state
        return self.policy(self.model)  # decide next action

Additional Example — Measuring Agent Performance

import random, time

class PerformanceTrackedAgent:
    """Agent that records its own decision quality over time."""
    def __init__(self, env):
        self.env = env
        self.history = []  # (percept, action, reward, timestamp)

    def run_episode(self, steps=100):
        total_reward = 0
        for _ in range(steps):
            percept = self.env.observe()
            action = self._policy(percept)
            reward = self.env.step(action)
            self.history.append((percept, action, reward, time.time()))
            total_reward += reward
        return total_reward

    def _policy(self, percept):
        """Simple policy: act randomly. Replace with learned policy."""
        return self.env.available_actions()[random.randint(0, 2)]

    def performance_summary(self):
        rewards = [h[2] for h in self.history]
        return {
            "total_reward": sum(rewards),
            "avg_reward": sum(rewards) / max(len(rewards), 1),
            "episodes": len(self.history),
        }

class SimpleGridEnv:
    def __init__(self, size=5):
        self.size = size
        self.pos = [0, 0]
        self.goal = [size-1, size-1]

    def observe(self):
        return tuple(self.pos)

    def available_actions(self):
        return ["up", "down", "left", "right"]

        if action == "up":    self.pos[0] = max(0, self.pos[0]-1)
        elif action == "down": self.pos[0] = min(self.size-1, self.pos[0]+1)
        elif action == "left":  self.pos[1] = max(0, self.pos[1]-1)
        elif action == "right": self.pos[1] = min(self.size-1, self.pos[1]+1)
        return 10 if self.pos == self.goal else -1  # reward

2A Brief History: Symbolic to Statistical to Generative

What & why. AI has moved through eras: symbolic reasoning (1950s-80s), statistical ML (1990s-2000s), deep learning (2010s), and generative/agentic AI (2020s). Each era solved different problems and revealed the limits of the previous one.

Internal Behavior — How Each Era Actually Works Symbolic era (1956–1980s): Programs encoded human knowledge as IF-THEN rules and logic predicates. Inference was mechanical deduction — forward chaining (from facts to conclusions) or backward chaining (from goal to supporting facts). The system never "learned" from data; a human programmer wrote every rule. Strength: explainability (every conclusion has a proof). Weakness: brittleness (rules break on edge cases, and writing rules for real-world complexity is intractable).

Statistical era (1990s–2000s): Instead of writing rules, we wrote learning algorithms. Decision trees, SVMs, and ensemble methods learned patterns from labeled data. The internal behavior changed fundamentally: the "knowledge" was no longer explicit rules but numerical weights and split thresholds derived from data statistics. Cross-validation replaced logical proof as the quality check. Strength: could handle noise and uncertainty. Weakness: needed hand-crafted features (a human still decided what to measure).

Deep learning era (2012–2020): Neural networks learned both the patterns AND the features from raw data. A CNN trained on images learns edge detectors in early layers, shape detectors in middle layers, and object classifiers in late layers — no human designs the features. The internal behavior is gradient descent through millions of parameters, with the chain rule (backpropagation) computing how each weight contributed to the error. Strength: superhuman performance on perception tasks. Weakness: needs massive data and compute, hard to explain.

Generative era (2020–now): Models learned to generate data, not just classify it. LLMs model P(next_token | context), diffusion models model P(image | noise). The internal behavior is sampling from learned distributions. Strength: creative, general-purpose. Weakness: hallucination, alignment challenges, unpredictable behavior.

3Search as Problem Solving

What & why. Classical AI treats many problems as search over a state space. Blind search (BFS/DFS) is complete but slow; informed search (A*) uses heuristics; adversarial search (minimax) handles games with opponents.

Internal Behavior — How Search Algorithms Actually Work BFS (Breadth-First Search): Maintains a FIFO queue. Explores all nodes at distance 1 from start, then all at distance 2, etc. Guarantees the shortest path for unweighted graphs because it never skips a shallower node. Memory cost: O(b^d) where b is branching factor and d is depth. For a branching factor of 10 and depth 5, that's 100,000 nodes in memory.

A* Search: Uses f(n) = g(n) + h(n) where g(n) is cost-so-far and h(n) is estimated cost-to-go. Explores the most promising node first (lowest f). The heuristic "directs" search toward the goal — like following a compass in a maze. A* is optimal if h never overestimates (admissible heuristic). With a perfect heuristic (h = true cost), A* explores only the optimal path. With h=0, it degrades to Dijkstra's algorithm.

Key insight — why A* beats BFS in practice: In a GPS navigation system with 10 million road segments, BFS would need to explore millions of nodes. A* with a straight-line-distance heuristic might explore only thousands, because every expansion moves toward the goal. The heuristic prunes the search space exponentially.

Beam Search (used in LLMs): A bounded variant that keeps only the top-k candidates at each step. Not optimal, but practical for large state spaces (like token sequences where branching factor is 50,000+ vocabulary tokens). This is how GPT generates text — beam search or sampling over the token distribution. 
from collections import deque
import heapq

def bfs(start, goal_test, expand):
    """Blind search — complete and optimal for unit costs."""
    frontier = deque([start]); visited = {start}
    while frontier:
        node = frontier.popleft()
        if goal_test(node): return node
        for child in expand(node):
            if child not in visited:
                visited.add(child); frontier.append(child)
    return None

def a_star(start, goal_test, expand, h):
    """Informed search — optimal when h is admissible."""
    frontier = [(h(start), 0, start)]  # (f, g, node)
    best = {start: 0}
    while frontier:
        _, g, node = heapq.heappop(frontier)
        if goal_test(node): return node
        for child, cost in expand(node):
            ng = g + cost
            if ng < best.get(child, float('inf')):
                best[child] = ng
                heapq.heappush(frontier, (ng + h(child), ng, child))
    return None

Additional Example — BFS vs A* Comparison on a Maze

import time

def make_grid(rows, cols, walls):
    """Create a grid world with walls."""
    grid = set()
    for r in range(rows):
        for c in range(cols):
            if (r, c) not in walls:
                grid.add((r, c))
    return grid

def neighbors(pos, grid):
    """Get valid neighboring cells."""
    r, c = pos
    result = []
    for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
        nr, nc = r+dr, c+dc
        if (nr, nc) in grid:
            result.append(((nr, nc), 1))  # cost 1
    return result

def manhattan(a, b):
    return abs(a[0]-b[0]) + abs(a[1]-b[1])

# Create a 10x10 maze
walls = {(1,i) for i in range(1,9)} | {(3,i) for i in range(1,9)} | \
        {(5,i) for i in range(1,9)} | {(7,i) for i in range(2,9)}
grid = make_grid(10, 10, walls)
start, goal = (0, 0), (9, 9)

# BFS — explores everything at distance d before d+1
t0 = time.time()
bfs_result = bfs(start, lambda n: n==goal, lambda n: neighbors(n, grid))
bfs_time = time.time() - t0

# A* — explores toward goal using heuristic

astar_result = a_star(start, lambda n: n==goal, lambda n: neighbors(n, grid), lambda n: manhattan(n, goal))
astar_time = time.time() - t0

import math

def beam_search(vocabulary, start_token, step_fn, beam_width=3, steps=5):
    """
    Beam search: keep top-k sequences at each step.
    This is how LLMs generate text (simplified).
    """
    # Start with one sequence
    beams = [(0.0, [start_token])]  # (log_prob, token_sequence)

    for step in range(steps):
        candidates = []
        for log_prob, seq in beams:
            # Get next-token probabilities from "model"
            next_probs = step_fn(seq)  # dict of {token: probability}
            for token, prob in next_probs.items():
                new_log_prob = log_prob + math.log(prob + 1e-10)
                candidates.append((new_log_prob, seq + [token]))

        # Keep only top-k
        candidates.sort(key=lambda x: -x[0])
        beams = candidates[:beam_width]

    return beams

4Game Playing: Minimax and Alpha-Beta

What & why. Zero-sum games are search with an adversary. Minimax assumes the opponent plays optimally; alpha-beta pruning cuts branches that cannot matter, making deep search feasible (Deep Blue searched ~200M positions/sec).

Internal Behavior — How Minimax and Alpha-Beta Actually Work Minimax works by propagating values up the game tree. At leaf nodes (game over or depth limit), a heuristic evaluation function scores the position (e.g., +10 for winning, -10 for losing). At MAX nodes (your turn), the algorithm picks the child with the highest value. At MIN nodes (opponent's turn), it picks the child with the lowest value. The result is the value of the game assuming optimal play from both sides.

The minimax value is the "true" value of the position — it's the score you're guaranteed if you play perfectly. The opponent's best play is already accounted for. That's why Deep Blue could evaluate millions of positions: each evaluation was a static heuristic, and minimax chose the path that maximizes the minimum guaranteed outcome.

Alpha-beta pruning observes that many branches cannot possibly affect the final decision. If MAX already found a move worth +5, and is exploring a branch where MIN can force it below +3, MAX will never choose that branch — so stop exploring it. The "alpha" tracks the best MAX has found; "beta" tracks the best MIN has found. When alpha ≥ beta, prune. With perfect move ordering, alpha-beta reduces the effective branching factor from b to √b — searching depth 12 as cheaply as depth 6.

Why this matters for modern AI: AlphaGo combined minimax-style tree search (MCTS) with neural network evaluation. The neural network replaced the hand-crafted evaluation function, but the search structure was classical minimax adapted for larger trees. 
def minimax(state, depth, maximizing):
    if depth == 0 or state.is_terminal():
        return state.evaluate()
    if maximizing:
        best = -float('inf')
        for move in state.legal_moves():
            best = max(best, minimax(move, depth-1, False))
        return best
    else:
        best = float('inf')
        for move in state.legal_moves():
            best = min(best, minimax(move, depth-1, True))
        return best

def alpha_beta(state, depth, alpha, beta, maximizing):
    if depth == 0 or state.is_terminal():
        return state.evaluate()
    if maximizing:
        value = -float('inf')
        for move in state.legal_moves():
            value = max(value, alpha_beta(move, depth-1, alpha, beta, False))
            alpha = max(alpha, value)
            if beta <= alpha: break  # prune
        return value
    else:
        value = float('inf')
        for move in state.legal_moves():
            value = min(value, alpha_beta(move, depth-1, alpha, beta, True))
            beta = min(beta, value)
            if beta <= alpha: break  # prune
        return value

Additional Example — Full Tic-Tac-Toe with Alpha-Beta

import math

class TicTacToe:
    def __init__(self, board=None, turn='X'):
        self.board = board or [' '] * 9
        self.turn = turn

    def legal_moves(self):
        return [i for i in range(9) if self.board[i] == ' ']

    def make_move(self, pos):
        new_board = self.board[:]
        new_board[pos] = self.turn
        return TicTacToe(new_board, 'O' if self.turn == 'X' else 'X')

    def is_terminal(self):
        return self.winner() is not None or ' ' not in self.board

    def winner(self):
        lines = [(0,1,2),(3,4,5),(6,7,8),(0,3,6),(1,4,7),(2,5,8),(0,4,8),(2,4,6)]
        for a,b,c in lines:
            if self.board[a] == self.board[b] == self.board[c] != ' ':
                return self.board[a]
        return None

    def evaluate(self):
        w = self.winner()
        if w == 'X': return 10
        if w == 'O': return -10
        return 0

def alpha_beta(state, depth, alpha, beta, maximizing):
    if depth == 0 or state.is_terminal():
        return state.evaluate()
    if maximizing:
        value = -math.inf
        for move in state.legal_moves():
            value = max(value, alpha_beta(state.make_move(move), depth-1, alpha, beta, False))
            alpha = max(alpha, value)
            if beta <= alpha: break
        return value
    else:
        value = math.inf
        for move in state.legal_moves():
            value = min(value, alpha_beta(state.make_move(move), depth-1, alpha, beta, True))
            beta = min(beta, value)
            if beta <= alpha: break
        return value

def best_move(state):
    best_val = -math.inf if state.turn == 'X' else math.inf
    move = None
    for m in state.legal_moves():
        val = alpha_beta(state.make_move(m), 9, -math.inf, math.inf, state.turn == 'X')
        if state.turn == 'X' and val > best_val:
            best_val, move = val, m
        elif state.turn == 'O' and val < best_val:
            best_val, move = val, m
    return move

game = TicTacToe()
moves = []
while not game.is_terminal():

    moves.append(m)
    game = game.make_move(m)

import time

def count_nodes_minimax(depth, branching):
    """Count nodes explored without pruning."""
    if depth == 0: return 1
    total = 0
    for _ in range(branching):
        total += count_nodes_minimax(depth - 1, branching)
    return total + 1  # +1 for this node

def count_nodes_alpha_beta(depth, branching, perfect_order=True):
    """Count nodes explored with alpha-beta (approximate)."""
    if depth == 0: return 1
    if perfect_order:
        # Perfect ordering: sqrt of minimax nodes
        return int(math.sqrt(count_nodes_minimax(depth, branching))) + 1
    return count_nodes_minimax(depth, branching)  # worst case

5Knowledge Representation and Logic

What & why. Symbolic AI represents knowledge as facts and rules in logic, then derives new conclusions by inference. This is explainable by construction: every conclusion has a proof trail.

Internal Behavior — How Rule Engines Actually Work Forward chaining (data-driven inference): Start with known facts. Scan all rules. If a rule's premises are all satisfied by current facts, fire the rule (add the conclusion to facts). Repeat until no new facts are derived. Example: facts = {fever, cough}. Rule: fever + cough → flu_suspect. Fire: add flu_suspect. Next rule: flu_suspect + high_risk → hospital. Can't fire (no high_risk fact). Done.

Backward chaining (goal-driven inference): Start with a goal. Find rules whose conclusion matches the goal. Check if those rules' premises are facts (or recursively prove them). If all premises are provable, the goal is true. Example: Goal = "hospital". Find rule: flu_suspect + high_risk → hospital. Need flu_suspect? Find rule: fever + cough → flu_suspect. Both are facts. Goal proven.

Why this matters: Forward chaining is used in production monitoring (new sensor data triggers alerts). Backward chaining is used in diagnosis (start with "what disease explains these symptoms?" and work backward). CLIPS, Drools, and Prolog are real-world implementations. Modern AI combines this with LLMs: the LLM generates rules, the rule engine guarantees correctness. 
# Forward chaining — simple production-rule engine
facts = {"fever", "cough"}
rules = [
    ({"fever", "cough"}, "flu_suspect"),
    ({"flu_suspect", "high_risk"}, "hospital"),
]

def forward_chain(facts, rules, max_iter=10):
    inferred = set(facts)
    for _ in range(max_iter):
        changed = False
        for prem, concl in rules:
            if prem <= inferred and concl not in inferred:
                inferred.add(concl); changed = True
        if not changed: break
    return inferred

print(forward_chain(facts, rules))  # {cough, fever, flu_suspect}

@dataclass

    name: str
    conditions: set
    action: Callable
    priority: int = 0

class ProductionEngine:
    def __init__(self):
        self.facts = set()
        self.rules = []
        self.log = []

    def add_fact(self, fact):
        self.facts.add(fact)
        self.log.append(f"+fact: {fact}")

    def add_rule(self, rule):
        self.rules.append(rule)

    def run(self):
        """Forward chain until no rules fire."""
        changed = True
        while changed:
            changed = False
            for rule in sorted(self.rules, key=lambda r: -r.priority):
                if rule.fired:
                    continue
                if rule.conditions <= self.facts:
                    result = rule.action(self.facts)
                    rule.fired = True
                    changed = True
                    self.log.append(f"FIRE: {rule.name} -> {result}")
                    if result:
                        self.facts.add(result)
        return self.facts

6Probability and Bayes' Rule

What & why. Real AI must act under uncertainty. Probability gives a principled calculus for beliefs: Bayes' rule updates beliefs as evidence arrives. Almost every ML model is Bayes' rule in disguise.

Internal Behavior — How Bayes' Rule Actually Computes Beliefs Bayes' rule says: P(H|E) = P(E|H) × P(H) / P(E). Let's trace through a concrete example step by step.

Step 1 — Prior P(H): Before seeing any evidence, what's the probability of the hypothesis? In spam filtering: 30% of emails are spam. This is the "prior belief."

Step 2 — Likelihood P(E|H): If the hypothesis is true, how likely is the evidence? If an email IS spam, the word "win" appears 80% of the time.

Step 3 — P(E|¬H): If the hypothesis is false (not spam), how likely is the evidence? In legitimate email, "win" appears 10% of the time.

Step 4 — Compute posterior: P(spam|"win") = 0.8 × 0.3 / (0.8 × 0.3 + 0.1 × 0.7) = 0.24 / 0.31 = 0.774.

Why this works: The denominator P(E) is the total probability of seeing the evidence, weighted across all hypotheses. The numerator is just the hypothesis-weighted likelihood. The result is a new belief that combines prior knowledge with observed evidence. Add more words, and each update compounds — this is Naive Bayes, and it's the engine behind email spam filters.

The deep connection to ML: Neural networks learn P(y|x) — the probability of label y given input x. This IS Bayes' rule, approximated by gradient descent instead of explicit computation. The network's weights encode the likelihood; the training data encodes the prior. 
# Bayes' rule: P(H|E) = P(E|H) * P(H) / P(E)
prior_spam = 0.3                 # P(spam)
p_word_given_spam = 0.8          # P("win" | spam)
p_word_given_ham = 0.1           # P("win" | ham)

def posterior(p_e_given_h, prior_h, p_e_given_not_h):
    prior_not = 1 - prior_h
    evidence = p_e_given_h * prior_h + p_e_given_not_h * prior_not
    return (p_e_given_h * prior_h) / evidence

posterior_spam = posterior(p_word_given_spam, prior_spam, p_word_given_ham)
print(f"P(spam | 'win') = {posterior_spam:.3f}")  # ~0.774

# P(class | words) ~ P(class) * prod(P(word | class))

import math
from collections import defaultdict

class NaiveBayes:
    def __init__(self):
        self.class_counts = defaultdict(int)
        self.word_counts = defaultdict(lambda: defaultdict(int))
        self.total_words = defaultdict(int)
        self.vocab = set()

    def train(self, documents, labels):
        """Train on (text, label) pairs."""
        for doc, label in zip(documents, labels):
            self.class_counts[label] += 1
            for word in doc.lower().split():
                self.word_counts[label][word] += 1
                self.total_words[label] += 1
                self.vocab.add(word)

    def _log_prob(self, word, label):
        """Laplace-smoothed log probability."""
        count = self.word_counts[label][word]
        total = self.total_words[label]
        vocab_size = len(self.vocab)
        return math.log((count + 1) / (total + vocab_size))

    def predict(self, doc):
        """Predict the most likely class."""
        words = doc.lower().split()
        total_docs = sum(self.class_counts.values())
        best_class, best_score = None, -float('inf')

        for label in self.class_counts:
            score = math.log(self.class_counts[label] / total_docs)
            for word in words:
                score += self._log_prob(word, label)
            if score > best_score:
                best_score = score
                best_class = label

        return best_class, best_score

def bayesian_sequence(prior, likelihoods, observed):
    """
    Show how beliefs update as evidence accumulates.
    Each observation shifts the posterior, which becomes the next prior.
    """
    beliefs = [prior]
    current_prior = prior

    for i, obs in enumerate(observed):
        p_obs_h = likelihoods["positive"][i] if obs else 1 - likelihoods["positive"][i]
        p_obs_not = likelihoods["negative"][i] if obs else 1 - likelihoods["negative"][i]

        evidence = p_obs_h * current_prior + p_obs_not * (1 - current_prior)
        posterior = (p_obs_h * current_prior) / evidence

        beliefs.append(posterior)
        current_prior = posterior  # posterior becomes next prior

    return beliefs

7Machine Learning in One Slide

What & why. Instead of hand-coding rules, ML learns them from examples. Supervised learning maps inputs to labels; unsupervised finds structure; reinforcement learning maximizes reward through trial and error. Generalization — performing on unseen data — is the entire game.

Internal Behavior — How a Classifier Actually Learns The learning loop: (1) Initialize model with random weights. (2) Feed training examples through the model → get predictions. (3) Compute loss: how wrong are the predictions compared to true labels? (4) Compute gradients: for each weight, how much did it contribute to the error? (5) Update weights: move them in the direction that reduces loss. (6) Repeat millions of times.

What the model "learns": A logistic regression model learns a decision boundary — a line (or hyperplane) that separates classes. The weights define this line. Training moves the line until it best separates spam from ham, cats from dogs, etc. The "feature" is what you measure (word frequencies, pixel values, sensor readings). The "label" is the answer you want to predict.

Why train/test split matters: If you evaluate on the same data you trained on, the model might have memorized the answers (overfitting). The train/test split simulates "unseen data" — the real test of generalization. A model that scores 99% on training but 60% on test has memorized, not learned. A model that scores 95% on both has genuinely learned patterns.

The bias-variance tradeoff: Simple models (few parameters) have high bias (they can't capture complex patterns) but low variance (they're stable across datasets). Complex models (many parameters) have low bias but high variance. The art of ML is finding the sweet spot.

class SimpleRL:
    def __init__(self, n_states, n_actions, lr=0.1, gamma=0.9):
        self.q = np.zeros((n_states, n_actions))
        self.lr = lr
        self.gamma = gamma

    def update(self, state, action, reward, next_state):
        best_next = self.q[next_state].max()
        td_target = reward + self.gamma * best_next
        td_error = td_target - self.q[state, action]
        self.q[state, action] += self.lr * td_error

    def policy(self, state):
        return self.q[state].argmax()

8Neural Networks and Backpropagation

What & why. A neural network is a stack of differentiable transformations. Backpropagation (chain rule + gradient descent) tunes millions of weights to minimize a loss. Universal approximation says a wide enough network can fit any continuous function.

Internal Behavior — How Backpropagation Actually Computes Gradients Forward pass: Input flows through each layer. Each neuron computes weighted_sum = Σ(weight_i × input_i) + bias, then applies an activation function (ReLU, sigmoid, etc.). The output of one layer becomes the input to the next. Final output is compared to the true label using a loss function (cross-entropy, MSE, etc.).

Backward pass (the chain rule): Starting from the loss, compute how much each weight contributed to the error. If the loss is L and a weight w connects neuron i to neuron j, then ∂L/∂w = ∂L/∂output × ∂output/∂weighted_sum × ∂weighted_sum/∂w. This is the chain rule of calculus applied layer by layer, backwards. Autograd frameworks (PyTorch, TensorFlow) build a computation graph during the forward pass, then traverse it in reverse to compute all gradients simultaneously.

Why it works: Gradient descent moves each weight in the direction that decreases the loss. Learning rate controls step size. Too large → overshooting and divergence. Too small → painfully slow convergence. Modern optimizers (Adam) adapt the learning rate per weight based on gradient history.

The "universal approximation" theorem: A single hidden layer with enough neurons can approximate any continuous function to arbitrary precision. But in practice, deep networks (many layers) are exponentially more efficient: a deep network needs O(n) neurons where a shallow one needs O(2^n).

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_deriv(x):
    s = sigmoid(x)
    return s * (1 - s)

# Simple 2-layer network: input(2) -> hidden(3) -> output(1)
np.random.seed(1)
W1 = np.random.randn(2, 3) * 0.5   # input -> hidden weights
b1 = np.zeros((1, 3))
W2 = np.random.randn(3, 1) * 0.5   # hidden -> output weights
b2 = np.zeros((1, 1))

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])  # XOR
y = np.array([[0], [1], [1], [0]])                 # XOR labels

lr = 2.0  # learning rate

for epoch in range(10000):
    # FORWARD PASS
    z1 = X @ W1 + b1          # pre-activation hidden
    a1 = sigmoid(z1)           # activation hidden
    z2 = a1 @ W2 + b2         # pre-activation output
    a2 = sigmoid(z2)           # activation output (prediction)

    # LOSS (binary cross-entropy)
    loss = -np.mean(y * np.log(a2 + 1e-8) + (1-y) * np.log(1-a2 + 1e-8))

    # BACKWARD PASS (chain rule)
    dz2 = a2 - y                          # dL/dz2 (simplified for sigmoid + BCE)
    dW2 = a1.T @ dz2 / len(X)            # dL/dW2
    db2 = dz2.mean(axis=0, keepdims=True)
    da1 = dz2 @ W2.T                     # dL/da1
    dz1 = da1 * sigmoid_deriv(z1)        # dL/dz1
    dW1 = X.T @ dz1 / len(X)            # dL/dW1
    db1 = dz1.mean(axis=0, keepdims=True)

    # UPDATE
    W2 -= lr * dW2; b2 -= lr * db2
    W1 -= lr * dW1; b1 -= lr * db1

    if epoch % 2000 == 0:
        print(f"Epoch {epoch}: loss={loss:.4f}")

print("\nXOR predictions:")
print(np.round(a2, 3))
# [[0.013], [0.985], [0.985], [0.018]] — learns XOR correctly

9CNNs, RNNs and Sequence Models

What & why. CNNs exploit spatial locality with shared-weight convolutions; RNNs process sequences with recurrent state but suffer vanishing gradients. Attention (transformers) replaced recurrence by letting every token look at every token directly.

Internal Behavior — How CNNs and Attention Actually Process Data CNNs (Convolutional Neural Networks): A small filter (e.g., 3×3 pixels) slides across the image. At each position, it computes the dot product between the filter weights and the pixel values — a local weighted sum. Early layers learn simple patterns (edges, gradients). Middle layers combine edges into shapes (circles, corners). Late layers combine shapes into objects (faces, cars). The key insight: the same filter is used everywhere (weight sharing), so the network learns "a vertical edge is a vertical edge regardless of where it appears." This makes CNNs translation-invariant and parameter-efficient.

RNNs (Recurrent Neural Networks): Process one token at a time, maintaining a hidden state vector that summarizes everything seen so far. At each step: new_hidden = activation(W × input + U × old_hidden). The hidden state is the "memory." Problem: gradients multiply through time steps. After 50+ steps, gradients either vanish (→0) or explode (→∞). LSTMs and GRUs add "gates" to control information flow — the forget gate decides what to discard from memory, the input gate decides what to add.

Attention (Transformers): Instead of compressing all history into one hidden state (RNN), attention lets each token directly look at every other token. For each token, compute: Query (what am I looking for?), Key (what do I contain?), Value (what information do I provide?). Attention weight = softmax(Q·K^T / √d). Output = attention_weight × V. This is parallelizable (unlike RNNs) and captures long-range dependencies without gradient decay.

import numpy as np

def attention(Q, K, V):
    """
    Scaled dot-product attention.
    Q, K, V: (seq_len, d_model) matrices
    """
    d_k = Q.shape[1]
    # Step 1: Compute attention scores
    scores = Q @ K.T / np.sqrt(d_k)  # (seq_len, seq_len)
    # Step 2: Apply softmax (row-wise)
    exp_scores = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights = exp_scores / exp_scores.sum(axis=-1, keepdims=True)
    # Step 3: Weighted sum of values
    output = weights @ V  # (seq_len, d_model)
    return output, weights

10Generative AI: Modeling the Data Distribution

What & why. Discriminative models answer "what class is this?"; generative models answer "what would a plausible example look like?" — by learning the probability distribution of the data. LLMs model text; diffusion models model images.

Internal Behavior — How Generative Models Actually Create Content LLMs (text generation): The model assigns a probability to every token in its vocabulary given the preceding context. P("cat" | "the small") = 0.4, P("dog" | "the small") = 0.2, etc. Generation is sequential sampling: pick a token from this distribution, append it to the context, compute the next distribution, repeat. Temperature controls randomness: T=0 always picks the highest-probability token (deterministic); T=1 samples proportionally to probabilities (creative); T>1 flattens the distribution (more random).

Diffusion models (image generation): Training: gradually add noise to images until they become pure noise (forward process). Train a neural network to predict the noise that was added at each step. Generation: start from random noise, iteratively denoise using the trained network. Each denoising step reveals a little more structure. After 50-1000 steps, the noise becomes a coherent image. Stable Diffusion uses a latent space (compressed representation) for efficiency.

GANs (Generative Adversarial Networks): Two networks compete: Generator creates fake images, Discriminator tries to tell real from fake. Training alternates: Generator gets better at fooling Discriminator, Discriminator gets better at detecting fakes. Equilibrium: Generator produces images indistinguishable from real data. GANs were state-of-the-art for image generation before diffusion models.

The key insight: All generative models learn P(data). LLMs learn P(word_n | word_1...word_{n-1}). Diffusion models learn P(image | noise_level). GANs learn a mapping from random noise to data. They differ in HOW they model the distribution, not WHAT they model.

import random

def sample_tokens(logits, temperature=0.8, top_p=0.9):
    # temperature: sharpen/flatten the distribution

    for idx, prob in ranked:
        keep.append(idx); cum += prob
        if cum >= top_p: break
    chosen = random.choice(keep)
    return chosen

import math, random

def softmax(logits, temperature=1.0):
    scaled = [l / temperature for l in logits]
    max_l = max(scaled)
    exps = [math.exp(l - max_l) for l in scaled]
    total = sum(exps)
    return [e / total for e in exps]

def generate(vocabulary, context_probs, steps=10, temperature=0.8, top_p=0.9):
    """Simulate LLM text generation with sampling strategies."""
    tokens = []
    probs = context_probs  # initial next-token distribution

    for step in range(steps):
        # Temperature sampling
        adjusted = softmax(probs, temperature)

        # Top-p (nucleus) filtering
        indexed = sorted(enumerate(adjusted), key=lambda x: -x[1])
        cumulative, filtered = 0, []
        for idx, p in indexed:
            cumulative += p
            filtered.append((idx, p))
            if cumulative >= top_p:
                break
        # Renormalize
        total = sum(p for _, p in filtered)
        filtered = [(i, p/total) for i, p in filtered]

        # Sample
        r = random.random()
        cumulative = 0
        chosen = filtered[0][0]
        for idx, p in filtered:
            cumulative += p
            if r <= cumulative:
                chosen = idx
                break

        tokens.append(vocabulary[chosen])
        # Get new probs (simulated — in real LLM, this is a forward pass)
        probs = [random.random() for _ in vocabulary]

    return tokens

import numpy as np

def forward_diffusion(image, timesteps=5, beta=0.1):
    """Add noise progressively — the forward process."""
    noisy_versions = [image.copy()]
    for t in range(timesteps):
        noise = np.random.randn(*image.shape)
        prev = noisy_versions[-1]
        noisy = np.sqrt(1 - beta) * prev + np.sqrt(beta) * noise
        noisy_versions.append(noisy)
    return noisy_versions

def reverse_diffusion(noisy_image, timesteps=5, beta=0.1):
    """Remove noise step by step — the reverse process (simplified)."""
    denoised = [noisy_image.copy()]
    for t in range(timesteps):
        prev = denoised[-1]
        # In real diffusion, a neural network predicts the noise
        # Here we simulate by slightly reducing noise
        clean = (prev - np.sqrt(beta) * 0.5 * np.random.randn(*prev.shape)) / np.sqrt(1 - beta)
        denoised.append(np.clip(clean, 0, 1))
    return denoised

11Capabilities, Limits and Evaluation

What & why. Modern AI is a general-purpose statistical engine: brilliant at pattern completion, unreliable at guaranteed correctness. Evaluating honestly (accuracy, calibration, robustness, safety) is the professional skill that separates production AI from demos.

Internal Behavior — Why AI Fails and How to Measure It Hallucination (confabulation): When an LLM doesn't know the answer, it doesn't say "I don't know" — it generates the most statistically likely completion, which might be a plausible-sounding but false statement. This happens because the model was trained to generate fluent text, not to verify truth. The probability distribution has no "uncertainty" token; every context has a most-likely next word.

Calibration failure: A well-calibrated model says "80% confident" and is correct 80% of the time. Most LLMs are overconfident: they say "90% confident" but are correct only 70% of the time. This is because the softmax probability reflects how likely the next token is in the training distribution, not whether the statement is factually correct.

Robustness failure: Small perturbations to inputs (adversarial examples) can change outputs dramatically. Adding one pixel to an image can flip a classifier's prediction. Adding "Ignore previous instructions" to a prompt can bypass safety guardrails. This is because neural networks learn statistical correlations, not causal models.

How to evaluate properly: (1) Use a held-out test set the model has never seen. (2) Measure not just accuracy but calibration (ECE), robustness (adversarial testing), and fairness (performance across demographics). (3) Test on edge cases, not average cases. (4) Compare against baselines (rule-based, random, human performance). (5) Run the evaluation multiple times to account for randomness.

def expected_calibration_error(confidences, corrects, n_bins=10):
    total = 0.0; count = 0
    for b in range(n_bins):
        lo, hi = b / n_bins, (b + 1) / n_bins
        mask = (confidences >= lo) & (confidences < hi)
        if mask.sum() == 0: continue
        acc = corrects[mask].mean()
        conf = confidences[mask].mean()
        total += mask.sum() * abs(acc - conf)
        count += mask.sum()
    return total / count

import numpy as np
from collections import defaultdict

class EvaluationFramework:
    """Production evaluation for any AI classifier."""

    def __init__(self):
        self.predictions = []
        self.labels = []
        self.confidences = []

    def add(self, prediction, label, confidence):
        self.predictions.append(prediction)
        self.labels.append(label)
        self.confidences.append(confidence)

    def accuracy(self):
        correct = sum(p == l for p, l in zip(self.predictions, self.labels))
        return correct / max(len(self.predictions), 1)

    def per_class_metrics(self):
        """Precision, recall, F1 per class."""
        classes = set(self.labels)
        metrics = {}
        for c in classes:
            tp = sum(p == c and l == c for p, l in zip(self.predictions, self.labels))
            fp = sum(p == c and l != c for p, l in zip(self.predictions, self.labels))
            fn = sum(p != c and l == c for p, l in zip(self.predictions, self.labels))
            precision = tp / max(tp + fp, 1)
            recall = tp / max(tp + fn, 1)
            f1 = 2 * precision * recall / max(precision + recall, 1e-8)
            metrics[c] = {"precision": precision, "recall": recall, "f1": f1}
        return metrics

    def calibration_error(self, n_bins=10):
        """Expected Calibration Error."""
        confs = np.array(self.confidences)
        corrects = np.array([p == l for p, l in zip(self.predictions, self.labels)])
        total_ece, count = 0, 0
        for b in range(n_bins):
            lo, hi = b / n_bins, (b + 1) / n_bins
            mask = (confs >= lo) & (confs < hi)
            if mask.sum() == 0: continue
            acc = corrects[mask].mean()
            conf = confs[mask].mean()
            total_ece += mask.sum() * abs(acc - conf)
            count += mask.sum()
        return total_ece / max(count, 1)

    def report(self):
        print(f"Accuracy: {self.accuracy():.3f}")
        print(f"Calibration Error: {self.calibration_error():.3f}")
        print("Per-class metrics:")
        for c, m in self.per_class_metrics().items():
            print(f"  {c}: P={m['precision']:.3f} R={m['recall']:.3f} F1={m['f1']:.3f}")

What & why. Combine search with a real domain: crawl a site as a graph and find the shortest navigation path between two pages using A* with a title-similarity heuristic.

Internal Behavior — How the Crawler + A* Works End-to-End Step 1 — Build the graph: Start at a URL. Fetch the HTML, parse all anchor tags to extract links. Each unique URL becomes a node in the graph; each hyperlink becomes an edge. Recurse (with depth limits and deduplication) to build the site map.

Step 2 — Run A*: Treat the site map as a weighted graph. Start node = the entry URL. Goal node = the target URL. The heuristic estimates "how different is this URL from the target?" — using string similarity or path depth. A* expands the most promising nodes first, finding the shortest path through the site.

Step 3 — Handle real-world messiness: URLs have fragments (#section), query parameters (?id=5), and redirects. Normalize URLs before adding to the graph. Respect robots.txt. Add delays between requests. Handle HTTP errors gracefully.

Why A* over BFS: On a large site (10,000 pages), BFS explores all pages at distance d before d+1. A* with a URL-similarity heuristic might explore only 500 pages to find the path, because it prioritizes pages whose URLs are similar to the target. 
import heapq
from urllib.parse import urljoin
import requests
from bs4 import BeautifulSoup

def expand(url, domain):
    try:
        html = requests.get(url, timeout=5).text
    except Exception:
        return []
    soup = BeautifulSoup(html, "html.parser")
    return [urljoin(url, a["href"]) for a in soup.find_all("a", href=True)
            if domain in urljoin(url, a["href"])]

def a_star_crawl(start, target, domain, max_steps=200):
    h = lambda u: abs(len(u) - len(target))  # simple heuristic
    frontier = [(h(start), 0, start)]
    best = {start: 0}
    while frontier and max_steps:
        _, g, node = heapq.heappop(frontier); max_steps -= 1
        if node.rstrip("/") == target.rstrip("/"):
            return g  # shortest path cost found
        for child in expand(node, domain):
            ng = g + 1
            if ng < best.get(child, float("inf")):
                best[child] = ng
                heapq.heappush(frontier, (ng + h(child), ng, child))
    return None

def build_site_map(start_url, domain, max_pages=50):
    """BFS crawl that builds a complete site map."""
    visited = set()
    queue = deque([(start_url, 0)])  # (url, depth)
    site_map = {}

    while queue and len(visited) < max_pages:
        url, depth = queue.popleft()
        if url in visited:
            continue
        visited.add(url)

        try:
            resp = requests.get(url, timeout=5)
            soup = BeautifulSoup(resp.text, "html.parser")
        except Exception as e:
            site_map[url] = {"depth": depth, "links": [], "error": str(e)}
            continue

        links = []
        for a in soup.find_all("a", href=True):
            full = urljoin(url, a["href"])
            parsed = urlparse(full)
            # Only follow same-domain links
            if parsed.netloc in domain and "#" not in full:
                links.append(full)
                if full not in visited:
                    queue.append((full, depth + 1))

        title = soup.title.string if soup.title else "No title"
        site_map[url] = {
            "depth": depth,
            "title": title.strip()[:80],
            "links": links[:20],  # limit
        }

    return site_map

def path_depth_heuristic(url, goal):
    """Heuristic 2: Path depth difference."""
    parts1 = url.rstrip('/').split('/')
    parts2 = goal.rstrip('/').split('/')
    return abs(len(parts1) - len(parts2))

def combined_heuristic(url, goal):
    """Heuristic 3: Combined (always admissible if both are)."""
    return max(url_similarity(url, goal) * 10, path_depth_heuristic(url, goal))

13Project 2 — Rule + ML Hybrid Classifier

What & why. The best systems combine symbolic rules (guaranteed behavior) with learned models (flexibility). Build a support-ticket router: rules for known patterns, ML fallback for the rest.

Internal Behavior — Why Hybrid Architecture Wins The routing decision tree: (1) Incoming ticket text arrives. (2) Rule engine scans for high-confidence patterns (exact keyword matches, regex patterns). If a rule fires with >90% historical accuracy, route immediately — no ML needed, latency is ~1ms. (3) If no rule fires, pass the text to the ML classifier (TF-IDF features → trained model). The ML model handles nuanced cases where keywords are ambiguous. (4) If the ML model's confidence is below threshold (e.g., 70%), flag for human review.

Why this beats pure ML: Rules are deterministic — the same input always produces the same output. This is critical for compliance: "all billing tickets must go to the billing team" is a rule, not a suggestion. ML models are probabilistic and can be wrong. By handling 40-60% of tickets with rules (the easy, well-known cases), you reduce ML workload and improve overall accuracy. The remaining 40-60% that need nuance go to the ML path.

The confidence cascade: Route with highest available confidence. Rule match (100% confidence) > ML with high confidence (>90%) > ML with medium confidence (70-90%, route with flag) > ML with low confidence (<70%, human review). This ensures every ticket gets routed appropriately for its difficulty.

class RoutingDecision:

class HybridRouter:
    def __init__(self):
        self.rules = []
        self.ml_model = None
        self.decisions = []
        self.stats = {"rule": 0, "ml": 0, "human": 0}

    def add_rule(self, keywords, team, priority=0):
        self.rules.append({"keywords": keywords, "team": team, "priority": priority})
        self.rules.sort(key=lambda r: -r["priority"])

    def route(self, text, ml_model=None, ml_vectorizer=None, confidence_threshold=0.7):
        # Step 1: Try rules (fast, deterministic)
        low_text = text.lower()
        for rule in self.rules:
            if any(kw in low_text for kw in rule["keywords"]):
                decision = RoutingDecision(
                    team=rule["team"], confidence=1.0,
                    source="rule", text_preview=text[:50]
                )
                self.decisions.append(decision)
                self.stats["rule"] += 1
                return decision

        # Step 2: Try ML (if available)
        if ml_model and ml_vectorizer:
            features = ml_vectorizer.transform([text])
            probs = ml_model.predict_proba(features)[0]
            max_conf = probs.max()
            team = ml_model.classes_[probs.argmax()]

            if max_conf >= confidence_threshold:
                decision = RoutingDecision(
                    team=team, confidence=max_conf,
                    source="ml", text_preview=text[:50]
                )
            else:
                decision = RoutingDecision(
                    team="human_review", confidence=max_conf,
                    source="human", text_preview=text[:50]
                )
            self.decisions.append(decision)
            self.stats[decision.source] += 1
            return decision

        # Step 3: Default to human review
        decision = RoutingDecision(
            team="human_review", confidence=0.0,
            source="human", text_preview=text[:50]
        )
        self.decisions.append(decision)
        self.stats["human"] += 1
        return decision

    def report(self):
        total = sum(self.stats.values())
        print(f"\nRouting Report ({total} tickets):")
        for source, count in self.stats.items():
            pct = count / max(total, 1) * 100
            print(f"  {source:>8}: {count:>4} ({pct:.1f}%)")

class AdaptiveRouter(HybridRouter):
    """Router that improves over time by learning from feedback."""

    def __init__(self):
        super().__init__()
        self.feedback_log = []
        self.rule_accuracy = {}

    def record_feedback(self, decision, actual_team):
        """Record whether the routing was correct."""
        correct = decision.team == actual_team
        self.feedback_log.append({
            "decision": decision,
            "actual": actual_team,
            "correct": correct,
        })
        # Update rule accuracy tracking
        key = (decision.source, decision.team)
        if key not in self.rule_accuracy:
            self.rule_accuracy[key] = {"correct": 0, "total": 0}
        self.rule_accuracy[key]["total"] += 1
        if correct:
            self.rule_accuracy[key]["correct"] += 1

    def should_remove_rule(self, rule_team, min_accuracy=0.8, min_samples=10):
        """Check if a rule should be removed due to poor accuracy."""
        for (source, team), stats in self.rule_accuracy.items():
            if source == "rule" and team == rule_team:
                acc = stats["correct"] / max(stats["total"], 1)
                if stats["total"] >= min_samples and acc < min_accuracy:
                    return True, acc
        return False, 0

    def feedback_report(self):
        total = len(self.feedback_log)
        correct = sum(1 for f in self.feedback_log if f["correct"])
        print(f"\nFeedback Report: {correct}/{total} correct ({correct/max(total,1)*100:.1f}%)")
        for (source, team), stats in self.rule_accuracy.items():
            acc = stats["correct"] / max(stats["total"], 1)
            print(f"  {source}/{team}: {acc:.2f} ({stats['correct']}/{stats['total']})")

14Project 3 — Mini LLM RAG Research Assistant

What & why. Put it together: retrieve documents, generate grounded answers, and evaluate the pipeline. This is the capstone pattern of the whole MasterHub, connecting search, embeddings, LLMs, and evaluation.

Internal Behavior — How RAG Connects Every AI Fundamental The RAG pipeline end-to-end: (1) Embed the query: convert the user's question into a vector using the same embedding model that was used on the documents. (2) Retrieve: compute cosine similarity between the query vector and all document vectors. Return the top-k most similar documents. This is the "search" component from Part I. (3) Prompt engineering: construct a prompt that includes the retrieved documents as context, plus instructions for the LLM to answer based only on that context. (4) Generate: the LLM produces an answer grounded in the retrieved evidence. (5) Cite: extract which documents supported the answer for traceability.

Why this works when the LLM alone fails: Without RAG, the LLM answers from its training data (which might be outdated or wrong). With RAG, the LLM's answer is constrained by provided documents. If the documents don't contain the answer, the LLM should say "I don't have enough information" instead of hallucinating. The retrieval step grounds the generation in facts.

The embedding step is the critical bridge: Embeddings convert semantic meaning into vectors where similar concepts are nearby. "What is the refund policy?" and "How do I get my money back?" map to nearby vectors, even though they share no words. This semantic search is why RAG works better than keyword search for natural language queries.

import numpy as np
from dataclasses import dataclass
from typing import List, Dict

@dataclass
class RAGResult:
    answer: str
    sources: List[str]
    scores: List[float]
    prompt_tokens: int
    retrieval_time_ms: float

class MiniRAG:
    """Complete RAG pipeline with evaluation metrics."""

    def __init__(self, documents: List[str]):
        self.documents = documents
        self.embeddings = self._embed_all(documents)
        self.query_log = []

    def _embed_all(self, texts):
        """In production, use sentence-transformers or OpenAI embeddings."""
        # Simplified: character-frequency vectors
        embeddings = []
        for text in texts:
            vec = np.zeros(26)
            for c in text.lower():
                if c.isalpha():
                    vec[ord(c) - ord('a')] += 1
            embeddings.append(vec / (np.linalg.norm(vec) + 1e-8))
        return np.array(embeddings)

    def retrieve(self, query: str, k: int = 3):
        """Find top-k most similar documents."""
        q_emb = self._embed_all([query])[0]
        similarities = self.embeddings @ q_emb
        top_indices = np.argsort(similarities)[-k:][::-1]
        return [(i, similarities[i]) for i in top_indices]

    def generate_prompt(self, query: str, k: int = 3):
        """Build a grounded prompt from retrieved context."""
        results = self.retrieve(query, k)
        context_parts = []
        for idx, score in results:
            context_parts.append(f"[Source {idx+1}, relevance={score:.3f}]: {self.documents[idx]}")
        context = "\n".join(context_parts)

        prompt = f"""Answer the question using ONLY the provided context.
If the context doesn't contain enough information, say so.

CONTEXT:
{context}

QUESTION: {query}

ANSWER (cite source numbers):"""

        return prompt, results

    def evaluate_retrieval(self, queries: List[Dict]):
        """Evaluate retrieval quality with precision@k and recall@k."""
        metrics = {"precision": [], "recall": [], "mrr": []}

        for q in queries:
            results = self.retrieve(q["query"], k=3)
            retrieved_indices = [r[0] for r in results]
            relevant = set(q.get("relevant_docs", []))

            # Precision@3
            hits = len(set(retrieved_indices) & relevant)
            metrics["precision"].append(hits / 3)

            # Recall@3
            metrics["recall"].append(hits / max(len(relevant), 1))

            # MRR (Mean Reciprocal Rank)
            for rank, idx in enumerate(retrieved_indices):
                if idx in relevant:
                    metrics["mrr"].append(1 / (rank + 1))
                    break
            else:
                metrics["mrr"].append(0)

        return {
            "precision@3": np.mean(metrics["precision"]),
            "recall@3": np.mean(metrics["recall"]),
            "mrr": np.mean(metrics["mrr"]),
        }

def fixed_size_chunk(text, size=100, overlap=20):
    """Strategy 1: Split into fixed-size chunks."""
    words = text.split()
    chunks = []
    for i in range(0, len(words), size - overlap):
        chunk = " ".join(words[i:i+size])
        chunks.append(chunk)
    return chunks

def sentence_chunk(text, max_sentences=3):
    """Strategy 2: Split by sentences."""
    sentences = text.replace(". ", ".|").split("|")
    chunks = []
    for i in range(0, len(sentences), max_sentences):
        chunks.append(" ".join(sentences[i:i+max_sentences]))
    return chunks

def semantic_chunk(text, min_chunk_size=50):
    """Strategy 3: Split at natural boundaries (paragraphs, sections)."""
    # Split by double newlines (paragraphs)
    paragraphs = text.split("\n\n")
    chunks = []
    current = ""
    for para in paragraphs:
        if len(current) + len(para) > 200 and current:
            chunks.append(current.strip())
            current = para
        else:
            current += "\n\n" + para
    if current.strip():
        chunks.append(current.strip())
    return chunks
