Part I · FoundationsTier 1 — one qubit at a time

1The Qubit: Superposition

What & why. A classical bit is 0 or 1. A qubit is a unit vector in a 2-D complex space: |ψ⟩ = α|0⟩ + β|1⟩, where |α|² + |β|² = 1. It exists in a superposition — both basis states at once — until measured, collapsing to |0⟩ with probability |α|² or |1⟩ with |β|².

# Qubit state vector: [alpha, beta]  (|alpha|^2 + |beta|^2 = 1)
# |0> = [1, 0]        |1> = [0, 1]
# Hadamard puts a qubit into equal superposition:
#   H|0> = (|0> + |1>) / sqrt(2)  -> 50% / 50% on measurement

import numpy as np
from qiskit import QuantumCircuit, execute, Aer

qc = QuantumCircuit(1, 1)   # 1 qubit, 1 classical bit
qc.h(0)                     # Hadamard: superposition
qc.measure(0, 0)            # measure qubit 0 -> bit 0

counts = execute(qc, Aer.get_backend("qasm_simulator"),
                 shots=1024).result().get_counts()
print(counts)               # ~ {'0': 512, '1': 512}

# The Bloch sphere: every single-qubit state is a point on a sphere
#   |0> = north pole, |1> = south pole, equator = superpositions
Where you'll use itEvery quantum program starts with state preparation and superposition; randomness from measurement is a feature, used for quantum random number generation.
Under the hoodMeasurement is non-deterministic and destructive — the same state measured twice gives the same outcome distribution but a different (random) sample each time.

2Single-Qubit Gates

What & why. Gates are unitary operations (U†U = I) — reversible rotations of the qubit on the Bloch sphere. The big three: Pauli X (flip), Hadamard H (superposition), and phase Z. Any single-qubit rotation is a composition of these.

# Gate matrices (acting on [alpha, beta])
# X = [[0, 1], [1, 0]]    # bit flip: X|0> = |1>
# Z = [[1, 0], [0, -1]]   # phase flip: Z|1> = -|1>
# H = (1/sqrt2) [[1, 1], [1, -1]]

X = np.array([[0, 1], [1, 0]])
H = np.array([[1, 1], [1, -1]]) / np.sqrt(2)

zero = np.array([1.0, 0.0])
print(X @ zero)            # [0, 1]  -> |1>
print(H @ zero)            # [0.707, 0.707]  -> superposition

# Unitarity check: H^dagger H = I
print(np.allclose(H.conj().T @ H, np.eye(2)))  # True

# No-cloning theorem: you cannot copy an unknown qubit state.
# This is why quantum error correction needs entanglement, not copies.
Where you'll use itState preparation in every circuit. Gate order matters: operations compose by matrix multiplication right-to-left.
Under the hoodQuantum gates are reversible, which is why quantum circuits are usually run "forwards" then measured — irreversible operations happen only at measurement.

Part II · EntanglementTier 2 — correlation with no classical analog

3Entanglement and Bell States

What & why. Apply CNOT after Hadamard and you create a Bell state: measuring one qubit instantly tells you the other, no matter the distance. Entanglement is the resource behind quantum teleportation, QKD, and exponential speedups.

# Bell state: |Phi+> = (|00> + |11>) / sqrt(2)
qc = QuantumCircuit(2, 2)
qc.h(0)          # superposition on qubit 0
qc.cx(0, 1)      # CNOT: if qubit0=1, flip qubit1
qc.measure([0, 1], [0, 1])

counts = execute(qc, Aer.get_backend("qasm_simulator"),
                 shots=1024).result().get_counts()
print(counts)     # ONLY {'00': 512, '11': 512}  -- never 01 or 10
                  # outcomes are perfectly correlated

# CNOT matrix (control q0, target q1):
#   |00>->|00>, |01>->|01>, |10>->|11>, |11>->|10>
Where you'll use itTeleportation, superdense coding, and the backbone of nearly every quantum algorithm's speedup.
Under the hoodThe correlated measurement outcomes are not classical correlation: the state is a single vector in a 4-D space that cannot be written as a product of two 1-qubit states.

4Quantum Parallelism and Deutsch-Jozsa

What & why. A circuit can evaluate a function on a superposition of all inputs at once. Deutsch-Jozsa is the simplest proof: one quantum query decides if a function is constant or balanced, where any classical deterministic algorithm needs up to 2^(n-1)+1 queries.

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

def deutsch_jozsa(n=3, balanced=True):
    qc = QuantumCircuit(n + 1, n)
    qc.x(n)                       # ancilla to |1>
    qc.h(range(n + 1))            # all in superposition

    if balanced:
        # balanced oracle: f(x) = parity of x (bit 0)
        for i in range(n):
            qc.cx(i, n)
    else:
        pass                      # constant oracle: f(x) = 0

    qc.h(range(n))                # interference
    qc.measure(range(n), range(n))

    counts = AerSimulator().run(qc, shots=1).result().get_counts()
    result = next(iter(counts))
    return "balanced" if result != "0" * n else "constant"

print(deutsch_jozsa(balanced=True))    # balanced
print(deutsch_jozsa(balanced=False))   # constant

# The interference step is the magic: correct paths reinforce,
# wrong paths cancel, so one run answers a question that
# takes exponentially many classical queries.
Where you'll use itThe conceptual foundation for Grover and Shor — understand this and you understand why quantum speedup exists.
Under the hoodAmplitude interference (constructive + destructive) is what turns parallelism into a speedup; without the second Hadamard layer you'd just measure a random superposition.

5Building and Simulating Circuits with Qiskit

What & why. Qiskit is the standard SDK: build circuits, simulate with statevector (exact) or qasm (sampled) backends, then optionally run on real IBM hardware. Circuit depth, qubit count and error rates are the practical constraints.

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_bloch_multivector

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)               # Bell state

# Exact statevector simulation (no measurement)
sv = AerSimulator().run(qc, shots=None).result()
#   statevector = [0.707, 0, 0, 0.707]   # |00> + |11>

# Noise models: simulate real hardware behavior
from qiskit_aer.noise import NoiseModel, depolarizing_error

noise.add_all_qubit_quantum_error(depolarizing_error(0.01, 1), ["u1", "u2", "u3"])
noisy = AerSimulator(noise_model=noise).run(qc.copy().measure_all(), shots=1024)

# Real hardware via IBM Quantum: select backend, transpile,
# then submit — jobs queue on real machines.
# Practical limits today: ~100-1000 qubits, noisy, shallow depth.
Where you'll use itEvery experiment in this chapter. Simulators are exact for <30 qubits; noise models tell you if an algorithm will survive on real hardware.
Under the hoodStatevector simulation stores 2^n amplitudes — exponential memory. That's why simulation tops out around 30-40 qubits and hardware is needed beyond.

Part III · AlgorithmsTier 3 — where quantum wins

6Grover's Search: Quadratic Speedup

What & why. Grover searches an unstructured database of N items in O(√N) queries vs O(N) classically. Amplitude amplification boosts the marked state's probability with each iteration — a 4x database search is 2x faster, 10,000 items is 100x faster.

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
import numpy as np

def grover(n=4, target=6):
    qc = QuantumCircuit(n)
    qc.h(range(n))                      # equal superposition

    # Oracle: flip phase of |target>
    qc.x(target); qc.h(target)
    qc.x(range(n)); qc.h(n - 1)
    qc.mcx(list(range(n - 1)), n - 1)   # multi-controlled X
    qc.h(n - 1); qc.x(range(n)); qc.h(target); qc.x(target)

    # Diffusion (amplitude amplification)
    qc.h(range(n)); qc.x(range(n))
    qc.h(n - 1); qc.mcx(list(range(n - 1)), n - 1)
    qc.h(n - 1); qc.x(range(n)); qc.h(range(n))
    qc.measure_all()

    counts = AerSimulator().run(qc, shots=1024).result().get_counts()
    top = max(counts, key=counts.get)
    return int(top, 2)                   # most likely answer

print(grover())                          # ~6 with high probability

# Iterations needed: ~ (pi/4) * sqrt(2^n)
# Too many iterations OVERSHOOTS (probability falls again).
Where you'll use itSearch, SAT solving, and as a subroutine in many algorithms. Practical today? Not yet — but it's the canonical speedup to know.
Under the hoodOracle + diffusion = reflection + reflection = rotation toward the target. The rotation angle is 2θ per iteration, hence the √N optimal count.

7Shor's Algorithm: Breaking RSA

What & why. Shor factors integers in polynomial time by finding the period of a modular function with the Quantum Fourier Transform. RSA's security rests on factoring being hard — Shor removes that assumption, which is why post-quantum cryptography is being standardized now.

# Shor's algorithm at a glance (period finding):
# 1. Pick random a coprime to N (N = number to factor)
# 2. Quantum part: find period r of f(x) = a^x mod N
#    - prepare superposition of x
#    - apply modular exponentiation
#    - QFT to read out the period
# 3. Classical post-processing:
#    factors = gcd(a^(r/2) - 1, N) and gcd(a^(r/2) + 1, N)

# Complexity: polynomial in log(N)
#   best classical: exp(O(c * log(N)^(1/3)))  (GNFS)
#   Shor: O((log N)^3) gates on O(log N) qubits

# Impact:
#   2048-bit RSA needs ~4100 logical qubits (millions of
#   physical qubits with error correction) — years away,
#   but harvest-now-decrypt-later is a live threat.
Where you'll use itUnderstanding why NIST standardized post-quantum algorithms (Kyber, Dilithium, SPHINCS+) — migration planning starts now.
Under the hoodThe QFT is the exponential-speedup engine: it maps periodicity in the time domain to a peak in the frequency domain, read out in one measurement.

8Quantum Error Correction Basics

What & why. Qubits decohere; you cannot copy them to back them up (no-cloning). Error correction instead encodes one logical qubit into many physical qubits with entangled codes, detecting and correcting errors via syndrome measurement — the reason real fault-tolerant machines need thousands of physical qubits per logical one.

# The 3-qubit bit-flip code (concept)
#   |0>  ->  |000>      |1>  ->  |111>
#   Encoding: two CNOTs entangle ancillas with the data qubit.
#   Error: one bit flips (e.g. |100> instead of |000>)
#   Syndrome: measure parity Z on (0,1) and (1,2)
#      (Z0Z1, Z1Z2) = (0,1) -> error on qubit 0, etc.
#   Correction: apply X to the flagged qubit. Done.

# Surface code (the leading approach):
#   - logical qubit = lattice of physical qubits
#   - syndrome measurements are continuous and local
#   - threshold ~1% physical error rate -> arbitrarily low
#     logical error with enough qubits

# Today: logical qubits demonstrated at ~100-1000 physical.
# Fault tolerance is THE engineering challenge of the field.
Where you'll use itEvaluating hardware claims: "1,000 qubits" almost always means physical qubits; useful computation needs logical qubits with error correction.
Under the hoodThreshold theorem: below a physical error threshold, more qubits lower logical error exponentially — the basis for scalable quantum computing.

Part IV · Quantum AITier 4 — hybrid classical-quantum learning

9Variational Circuits: VQE and QAOA

What & why. NISQ-era workhorses are hybrid: a parameterized quantum circuit (ansatz) + a classical optimizer. VQE finds ground-state energies (chemistry/drugs); QAOA solves combinatorial optimization (routing, scheduling). The classical loop tunes circuit parameters to minimize a cost.

from qiskit.circuit.library import TwoLocal
from qiskit_algorithms import VQE, MinimumEigensolver
from qiskit_algorithms.optimizers import COBYLA
from qiskit.quantum_info import SparsePauliOp

# H2 molecule Hamiltonian (simplified)
H = SparsePauliOp.from_list([("II", -1.05), ("ZI", 0.39),
                             ("IZ", -0.39), ("ZZ", 0.18),
                             ("XX", 0.18)])

ansatz = TwoLocal(2, "ry", "cx", reps=1,
                  entanglement="linear")   # parameterized circuit

vqe = VQE(ansatz, optimizer=COBYLA(maxiter=200),
          quantum_instance=Aer.get_backend("statevector_simulator"))
result = vqe.compute_minimum_eigenvalue(H)
print(result.eigenvalue.real)   # ~ -1.85 Ha (H2 ground state)

# Hybrid loop:  classical opt  <->  quantum circuit
#   theta --(circuit)--> expectation value --(cost)--> new theta
Where you'll use itQuantum chemistry simulation, portfolio optimization, logistics — the most likely first commercial quantum wins.
Under the hoodVQE's ansatz choice determines expressivity vs noise: too shallow underfits, too deep dies of decoherence — the "barren plateau" problem makes training hard at scale.

10Quantum Machine Learning (QML)

What & why. QML encodes classical data into quantum states and learns with parameterized circuits. The hope: quantum feature spaces that classical models cannot easily capture. Reality check: on current hardware, quantum kernels and circuits rarely beat classical baselines — the field is honest about this, and that's a feature.

11Quantum Annealing and Real-World Constraints

What & why. D-Wave-style annealers solve Ising/QUBO problems by letting a system relax to a minimum energy state. They are specialized (optimization only) but already used commercially — different technology from gate-model quantum computers.

# QUBO: map optimization to binary quadratic form
#   minimize  x^T Q x   (x in {0,1}^n)
# QUBO for a simple 2-var problem:
#   cost(x) = -3x1 - 2x2 + 4 x1 x2
Q = {(0,0): -3, (1,1): -2, (0,1): 4/2 + 4/2}  # symmetric

# Read the optimum by brute force (for demo):
import itertools
best = min(itertools.product([0,1], repeat=2),
           key=lambda x: sum(Q[(i,j)] * a * b
                             for (i,j),a,b in
                             [( (0,0), x[0], x[0]),
                              ( (1,1), x[1], x[1]),
                              ( (0,1), x[0], x[1]),
                              ( (1,0), x[0], x[1])]))
print(best)  # optimal assignment

# Annealer workflow: problem -> QUBO -> embed -> anneal -> sample
# Constraints: hardware graph is sparse -> embedding overhead;
#              precision is limited; sampling is stochastic.
Where you'll use itTraffic routing, scheduling, portfolio selection, drug-docking — the pragmatic "quantum-inspired + annealing" space where results exist today.
Under the hoodClassical solvers (Gurobi, simulated annealing on GPU) often match or beat annealers at comparable cost; the honest framing is "hybrid" — annealers accelerate specific structures.

12Project 1 — Quantum Random Number Generator

What & why. Measurement of a superposition is genuinely random — no PRNG seed, no algorithm. Build a QRNG and run a statistical sanity check (it should pass frequency tests that a weak PRNG fails).

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

def qrng_bits(n_bits=8, shots=1):
    qc = QuantumCircuit(n_bits, n_bits)
    qc.h(range(n_bits))          # all qubits in superposition
    qc.measure(range(n_bits), range(n_bits))
    counts = AerSimulator().run(qc, shots=shots).result().get_counts()
    return next(iter(counts))    # e.g. '10100110'

bits = [int(qrng_bits(8), 2) for _ in range(1000)]
# sanity: uniform-ish distribution
import collections
c = collections.Counter(b // 100 for b in bits)  # 0-9 buckets
print(sorted(c.items()))

# Real hardware adds entropy from device noise too.
# Use case: lottery draws, key generation, fair sampling.

13Project 2 — VQE Ground State of H2

What & why. Reproduce a real chemistry result: compute the H2 molecule's ground-state energy curve by scanning bond length with VQE, and compare against the exact diagonalization.

from qiskit.quantum_info import SparsePauliOp
from qiskit_algorithms import VQE
from qiskit_algorithms.optimizers import SPSA
from qiskit.circuit.library import TwoLocal

def h2_hamiltonian(scale):
    # scale ~ interatomic distance proxy (simplified model)
    coeffs = {"II": -1.05, "ZI": 0.39*scale, "IZ": -0.39*scale,
              "ZZ": 0.18, "XX": 0.18}
    return SparsePauliOp.from_list(list(coeffs.items()))

for s in [0.8, 1.0, 1.2, 1.4]:
    H = h2_hamiltonian(s)
    ansatz = TwoLocal(2, "ry", "cx", reps=2)
    result = VQE(ansatz, optimizer=SPSA(maxiter=300),
                 quantum_instance=Aer.get_backend("statevector_simulator")
                 ).compute_minimum_eigenvalue(H)
    print(f"scale={s}: E={result.eigenvalue.real:.4f}")

# Plot E vs scale -> dissociation curve.
# Compare with exact: np.linalg.eigvalsh(H.to_matrix()).min()
